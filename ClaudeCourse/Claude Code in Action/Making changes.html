LLM용 전체 코스 노트 복사

개발 환경에서 Claude와 함께 작업할 때, 기존 프로젝트를 변경해야 하는 경우가 자주 생깁니다. 이 가이드에서는 스크린샷을 활용한 시각적 커뮤니케이션과 Claude의 고급 추론 기능 활용 등 변경 사항을 효과적으로 구현하기 위한 실용적인 기법을 다룹니다.

정확한 커뮤니케이션을 위한 스크린샷 활용

스크린샷은 Claude와 소통하는 가장 효과적인 방법 중 하나입니다. 인터페이스의 특정 부분을 수정하고 싶을 때, 스크린샷을 찍으면 Claude가 정확히 어떤 부분을 말하는지 이해하는 데 도움이 됩니다.

Claude에 스크린샷을 붙여넣으려면 Ctrl+V를 사용하세요(macOS에서는 Cmd+V가 아닙니다). 이 키보드 단축키는 채팅 인터페이스에 스크린샷을 붙여넣기 위해 특별히 설계되었습니다. 이미지를 붙여넣은 후, 애플리케이션의 해당 영역에 대한 구체적인 변경을 Claude에게 요청할 수 있습니다.

플래닝 모드

코드베이스 전반에 걸쳐 광범위한 탐색이 필요한 복잡한 작업의 경우, 플래닝 모드를 활성화할 수 있습니다. 이 기능을 사용하면 Claude가 변경 사항을 구현하기 전에 프로젝트를 철저히 탐색합니다.

Shift + Tab을 두 번 눌러 플래닝 모드를 활성화하세요(이미 편집 자동 수락 상태라면 한 번만 누르면 됩니다). 이 모드에서 Claude는 다음과 같이 동작합니다:

  • 프로젝트의 더 많은 파일을 읽습니다
  • 상세한 구현 계획을 작성합니다
  • 수행하려는 작업을 정확하게 보여줍니다
  • 진행하기 전에 사용자의 승인을 기다립니다

이를 통해 계획을 검토하고, Claude가 중요한 사항을 놓쳤거나 특정 시나리오를 고려하지 않은 경우 방향을 재설정할 수 있습니다.

씽킹 모드

Claude는 "씽킹(thinking)" 모드를 통해 다양한 수준의 추론 기능을 제공합니다. 이를 통해 Claude가 솔루션을 제공하기 전에 복잡한 문제를 더 깊이 생각하는 데 더 많은 시간을 할애할 수 있습니다.

사용 가능한 씽킹 모드는 다음과 같습니다:

  • "Think" - 기본 추론
  • "Think more" - 확장 추론
  • "Think a lot" - 포괄적 추론
  • "Think longer" - 장시간 추론
  • "Ultrathink" - 최대 추론 능력

각 모드는 Claude에게 점진적으로 더 많은 토큰을 제공하여 어려운 문제를 더 깊이 분석할 수 있게 합니다.

플래닝 모드와 씽킹 모드의 활용 시점

두 기능은 서로 다른 유형의 복잡성을 처리합니다:

플래닝 모드가 적합한 경우:

  • 코드베이스에 대한 광범위한 이해가 필요한 작업
  • 여러 단계로 이루어진 구현
  • 여러 파일이나 컴포넌트에 영향을 미치는 변경

씽킹 모드가 적합한 경우:

  • 복잡한 논리 문제
  • 어려운 버그 디버깅
  • 알고리즘적 도전 과제

넓이와 깊이 모두가 필요한 작업에는 두 모드를 함께 사용할 수 있습니다. 다만, 두 기능 모두 추가 토큰을 소모하므로 사용 시 비용을 고려해야 합니다.
