도구 연결하기

예상 소요 시간: 20분

학습 목표

이 레슨을 마치면 다음을 할 수 있게 됩니다:

  • 커넥터가 무엇이며 Claude 사용 시 왜 중요한지 설명할 수 있습니다
  • 커넥터 디렉터리를 탐색하고 첫 번째 연결을 설정할 수 있습니다
  • Claude와의 대화에서 연결된 도구를 효과적으로 사용할 수 있습니다

동영상

핵심 내용

  • 커넥터는 Claude를 단순한 어시스턴트에서 정보를 갖춘 협력자로 변환합니다. Claude가 매일 사용하는 것과 동일한 도구, 데이터, 컨텍스트에 접근할 수 있게 해줍니다. 매번 대화를 처음부터 시작하는 대신, Claude가 실제 정보와 직접 작업할 수 있습니다.
  • 커넥터를 통해 Claude는 정보를 읽고 사용자를 대신해 작업을 수행할 수 있습니다. 커넥터와 부여된 권한에 따라 Claude는 파일 검색, 문서 조회, 데이터 분석, 새 콘텐츠 생성, 레코드 업데이트, 연결된 애플리케이션 전반의 작업 실행 등을 대화 안에서 모두 처리할 수 있습니다.
  • 커넥터는 Model Context Protocol(MCP)을 기반으로 합니다. MCP를 AI의 USB-C라고 생각하세요. 단일하고 일관된 인터페이스를 통해 Claude가 다양한 애플리케이션에 연결할 수 있는 범용 표준입니다. 이 개방형 표준 덕분에 개발자는 어떤 도구에든 커넥터를 만들 수 있으며, 해당 커넥터는 Claude와 원활하게 작동합니다.
  • 커넥터에는 웹 커넥터와 데스크톱 확장 기능 두 가지 유형이 있습니다. 웹 커넥터는 Claude를 Google Drive, Notion, Slack, Asana 같은 클라우드 서비스와 연결합니다. 데스크톱 확장 기능은 Claude Desktop 앱을 통해 컴퓨터에서 로컬로 실행되어 Claude가 로컬 파일과 네이티브 애플리케이션에 접근할 수 있게 합니다.

도구 찾기 및 연결하기

Anthropic은 claude.ai/directory에서 권장 커넥터 디렉터리를 관리합니다. 디렉터리는 두 개의 탭으로 구성되어 있습니다:

  • 웹 : 클라우드 서비스 및 애플리케이션 (Gmail, Notion, Slack, Asana, Linear, Stripe 등 다수)
  • 데스크톱 확장 기능 : Claude Desktop 앱을 통해 컴퓨터에서 실행되는 로컬 도구

사용 가능한 커넥터를 탐색하려면 채팅 창 왼쪽 하단의 "검색 및 도구" 버튼을 클릭한 다음 "커넥터 추가"를 선택할 수도 있습니다.

웹 커넥터 설정하기

클라우드 서비스를 연결하는 방법은 다음과 같습니다:

  1. 커넥터 찾기 : claude.ai/directory로 이동하거나 채팅에서 "검색 및 도구" > "커넥터 추가" 클릭
  2. 연결 클릭 : 추가할 커넥터 선택
  3. 인증 : 서비스 로그인 페이지로 이동합니다. 기존 자격 증명으로 로그인하세요
  4. 권한 부여 : Claude가 요청하는 특정 권한을 검토한 후 접근 허가
  5. 연결 테스트 : Claude로 돌아가 "내 [도구 이름]에 접근할 수 있나요?"와 같은 간단한 요청 시도

연결되면 부여한 권한에 따라 Claude는 해당 서비스 내에서 검색, 읽기, 경우에 따라 작업 수행도 할 수 있습니다.

데스크톱 확장 기능

데스크톱 확장 기능은 웹 인터페이스가 아닌 Claude Desktop 앱이 필요합니다. 이 확장 기능을 통해 Claude는 로컬 애플리케이션, 파일 시스템, macOS 또는 Windows의 네이티브 기능과 상호작용할 수 있습니다.

데스크톱 확장 기능의 예시:

  • 문서 읽기 및 정리를 위한 로컬 파일 접근
  • 자동화된 웹 작업을 위한 브라우저 제어
  • 네이티브 애플리케이션 통합 (예: 디자인 작업을 위한 Figma)

데스크톱 확장 기능 설치 방법:

  1. Claude Desktop 앱을 다운로드하여 설치
  2. 앱을 열고 설정 > 확장 기능으로 이동
  3. 사용 가능한 확장 기능을 탐색하고 설치 클릭
  4. 해당 확장 기능에 특정한 추가 설정 단계 따르기

업무에서 커넥터 활용하기

도구를 연결하면 Claude는 요청에 응답할 때 해당 도구를 고려합니다.

동영상: 커넥터 사용하기

연결된 도구를 활용하는 실용적인 방법들입니다:

프로젝트 관리 (Asana, Linear, Jira)

  • "이번 주 마감인 최우선 작업은 무엇인가요?"
  • "Q4 예산 제안서 검토를 위한 새 작업을 만들어 주세요"
  • "제품 출시 프로젝트의 현재 상태를 요약해 주세요"

커뮤니케이션 (Slack, Gmail)

  • "벤더 계약을 논의했던 이메일 스레드를 찾아 주세요"
  • "#marketing 채널의 최신 메시지에 대한 답장 초안을 작성해 주세요"
  • "어제 논의에서 팀이 일정에 대해 어떤 결정을 내렸나요?"

문서 관리 (Notion, Google Drive, Confluence)

  • "브랜드 보이스 가이드라인에 대해 문서를 검색해 주세요"
  • "지난주 제품 검토 회의록을 요약해 주세요"
  • "스타일 가이드에서 축약형 사용에 대해 어떻게 말하고 있나요?"

비즈니스 도구 (Stripe, PayPal, Salesforce)

  • "지난 분기 매출 추세를 보여 주세요"
  • "Acme Corp 기회의 현재 상태는 어떤가요?"
  • "최근 $1,000 이상의 거래 목록을 보여 주세요"

보안 및 권한

Claude를 외부 서비스에 연결하면 해당 서비스 내의 데이터를 읽거나 경우에 따라 수정할 수 있는 권한을 부여하게 됩니다. 다음은 중요한 고려 사항들입니다:

  • 범위 지정 접근 : 권한은 커넥터가 필요로 하는 것에만 특정되며, 각 애플리케이션 메뉴에서 개별 권한을 켜거나 끌 수 있습니다.
  • Claude는 사용자가 볼 수 있는 것만 봅니다 : Claude는 사용자가 접근할 수 있는 데이터에만 접근할 수 있습니다. 업무용 이메일을 연결해도 CEO의 받은 편지함이 아닌 자신의 것에만 접근할 수 있습니다.
  • 언제든지 취소 가능 : Claude 설정 또는 서드파티 서비스의 보안 설정을 통해 서비스 연결을 해제할 수 있습니다.

레슨 되돌아보기

계속 진행하기 전에 다음을 생각해 보세요:

  • 매일 사용하는 업무 도구 중 Claude에 연결하면 가장 유용할 것은 무엇인가요?
  • 현재 정보를 복사하여 붙여넣어야 하는 작업 중 커넥터가 자동으로 처리할 수 있는 것은 무엇인가요?
  • 여러 연결된 소스의 데이터를 결합하면 상당한 시간을 절약할 수 있는 워크플로우가 있나요?
