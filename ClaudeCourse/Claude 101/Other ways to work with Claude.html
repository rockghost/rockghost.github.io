Claude와 함께하는 다른 방법들

예상 소요 시간: 10분

학습 목표

이 레슨을 마치면 다음을 할 수 있습니다:

  • Claude Code, Slack용 Claude, Excel용 Claude, Chrome용 Claude를 포함한 추가 Claude 제품을 언제 사용해야 하는지 이해하기

이 과정의 시작 부분에서 언급했듯이, Claude는 하나의 지능입니다. Claude.ai는 Claude와 함께 작업하는 하나의 방법일 뿐입니다.

Claude는 이미 사용하고 있는 환경에서 만나도록 설계된 여러 전문 도구에서도 사용할 수 있습니다. 이 레슨에서는 특정 워크플로우와 사용 사례에 맞게 조정된 Claude와 함께하는 네 가지 추가 방법을 소개합니다.

Claude Code

Claude Code는 터미널, IDE, 브라우저, 심지어 Slack에서도 여러분이 작업하는 곳에서 함께 작동하는 에이전틱 코딩 도구입니다. 코드베이스를 이해하고, 명령을 실행하며, 자연어를 통해 전체 개발 워크플로우를 처리합니다.

Claude Code를 사용해야 할 때:

  • 필요한 것을 평이한 영어로 설명하여 기능을 구축하고, Claude가 코드를 작성하고, 테스트를 실행하고, 커밋을 생성하도록 하고 싶을 때
  • 오류 메시지를 붙여넣어 Claude가 코드베이스를 분석하여 문제를 식별하고 수정하도록 하여 디버깅이 필요할 때
  • 낯선 코드베이스를 탐색하며 서로 다른 부분이 어떻게 함께 작동하는지에 대해 질문하고 싶을 때
  • lint 오류 수정, 병합 충돌 해결, 릴리스 노트 작성과 같은 지루한 작업을 자동화하고 싶을 때
  • 별도의 인터페이스로 전환하지 않고 기존 IDE 및 개발 도구와 함께 터미널에서 작업하는 것을 선호할 때

Slack의 Claude

Claude는 Slack과 직접 통합되어 채널 및 스레드에서 도움을 받거나 Slack 컨텍스트를 Claude 대화로 가져올 수 있습니다.

Slack에서 Claude를 사용해야 할 때:

  • Slack을 떠나지 않고 메시지에 대한 답변을 초안 작성하거나, 긴 스레드를 요약하거나, 복잡한 토론을 분석하고 싶을 때
  • Claude가 워크스페이스의 관련 대화와 공유 문서를 모아 회의 준비를 도와주어야 할 때
  • 새로운 팀에 온보딩 중이며 채널 기록을 검토하여 진행 중인 프로젝트를 이해하는 데 도움이 필요할 때
  • 버그 리포트나 기능 토론에서 직접 코딩 작업을 넘기고 싶을 때—@Claude를 태그하기만 하면 주변 컨텍스트를 사용하여 Claude Code 세션을 시작할 수 있습니다
  • 대화 중에 산업 트렌드, 기술 개념 또는 회사 정보에 대한 답변을 신속하게 얻어야 할 때

Excel용 Claude

Excel용 Claude는 사이드바를 통해 Microsoft Excel에 Claude를 직접 가져와 대화를 통해 스프레드시트를 분석하고, 이해하고, 수정할 수 있게 해줍니다.

Excel용 Claude를 사용해야 할 때:

  • 복잡한 다중 탭 워크북으로 작업하며 시트 전반에서 특정 수식이나 계산 흐름이 어떻게 작동하는지 이해하고 싶을 때
  • 수식 종속성과 관계를 유지하면서 모델 전반의 가정이나 입력값을 업데이트해야 할 때
  • #REF!, #VALUE!, 또는 순환 참조와 같은 스프레드시트 오류를 디버깅하며 Claude가 출처를 추적하고 수정 방법을 제안하도록 하고 싶을 때
  • 적절한 수식 구조를 유지하면서 새 스프레드시트를 만들거나 기존 템플릿에 데이터를 채우고 싶을 때
  • 데이터를 시각화하기 위해 피벗 테이블이나 차트를 빠르게 만들어야 할 때

Chrome용 Claude

Chrome용 Claude는 Google Chrome에 Claude를 사이드바로 추가하는 브라우저 확장 프로그램입니다. 작업 중인 내용을 관찰하고 브라우저 내에서 직접 작업을 수행할 수 있습니다.

Chrome용 Claude를 사용해야 할 때:

  • 브라우징하면서 기사, 연구 논문, 또는 웹 페이지를 요약하고 싶을 때
  • 이메일 답변 초안 작성이나 받은 편지함 관리에 도움이 필요할 때
  • 반복적인 양식을 작성하고 있으며 프로세스를 자동화하고 싶을 때
  • 각 단계를 수동으로 클릭하지 않고 웹사이트 기능을 테스트하거나 다단계 워크플로우를 탐색하고 싶을 때
  • 탭과 작업 사이를 이동하면서 컨텍스트를 유지하는 브라우징 어시스턴트가 필요할 때

중요 참고사항: Chrome용 Claude는 현재 연구 미리보기 단계입니다. Anthropic은 신뢰할 수 있는 웹사이트에서 저위험 작업에 사용할 것을 권장합니다. 확장 프로그램은 구매나 개인 데이터 공유와 같은 고위험 작업을 수행하기 전에 권한을 요청하며, 특정 카테고리의 웹사이트(금융 서비스, 성인 콘텐츠)는 기본적으로 차단됩니다.

이용 가능 여부: Chrome용 Claude는 Claude Max 구독자에게 제공됩니다. claude.ai/chrome에서 대기자 명단에 가입하세요.

요약

이러한 각 도구는 여러분이 작업하는 특정 환경으로 Claude의 기능을 확장합니다:

도구 최적 용도 실행 환경
Claude.ai 일반 작업, 리서치, 글쓰기, 분석, 파일 생성 웹, 데스크톱, 모바일 앱
Claude Code 소프트웨어 개발, 코드베이스 탐색, git 워크플로우 터미널/커맨드 라인, IDE, 또는 브라우저
Slack의 Claude/Claude Code 팀 협업, 회의 준비, 컨텍스트 내 빠른 답변 Slack 워크스페이스
Excel용 Claude 스프레드시트 분석, 재무 모델링, 수식 디버깅 Microsoft Excel 사이드바
Chrome용 Claude 웹 리서치, 이메일 관리, 브라우저 자동화 Chrome 브라우저 사이드바
