동영상

코드 리뷰

Claude Code에는 git 워크플로우를 더 빠르게 만들어주는 몇 가지 내장 기능이 있습니다. 하나씩 살펴보겠습니다.

서브에이전트를 활용한 리뷰

PR을 푸시하기 전에, Claude에게 서브에이전트를 사용하여 변경 사항을 리뷰하도록 요청하세요. 서브에이전트는 자체 컨텍스트 윈도우에서 새로운 시각으로 실행됩니다 — 방금 세션에서 코드를 작성한 메인 에이전트의 편향을 가지고 있지 않습니다.

코드 리뷰어 서브에이전트를 만들 때는 읽기 전용 도구로 제한하세요. 리뷰어는 문제를 지적해야 하지, 파일을 편집해서는 안 됩니다. 서브에이전트 설정을 리포지토리에 커밋하여 팀 전체가 동일한 리뷰어를 사용하도록 하세요.

/commit-push-pr 스킬

/commit-push-pr 스킬은 커밋, 푸시, PR 생성을 한 번에 처리합니다. 각각을 수동으로 하는 대신 스킬을 실행하기만 하면 Claude가 알아서 처리합니다.

CLAUDE.md에 채널이 나열된 Slack MCP 서버가 설정되어 있으면, PR 링크가 팀 채널에 자동으로 게시됩니다.

--from-pr을 활용한 세션 연결

Claude가 gh pr create를 통해 PR을 생성하면, 세션이 해당 PR에 자동으로 연결됩니다. 나중에 다시 돌아와야 할 때 — 리뷰 코멘트에 대응하거나 실패한 빌드를 수정하는 경우 — 다음을 실행하세요: 

claude --from-pr <PR_NUMBER>

이전에 중단한 곳에서 바로 이어서 작업할 수 있습니다.

요약

푸시하기 전에 서브에이전트를 사용하여 편향 없는 코드 리뷰를 받으세요. /commit-push-pr을 사용하여 커밋부터 PR까지의 전체 흐름을 한 번에 처리하세요. 그리고 --from-pr을 사용하여 나중에 PR 작업을 재개하세요. 작은 기능들이지만, 일상적인 워크플로우에서 많은 번거로움을 제거해 줍니다.
