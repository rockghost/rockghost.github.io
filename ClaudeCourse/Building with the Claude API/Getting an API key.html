다음 영상에서는 Anthropic API에 요청을 보내는 방법을 알아볼 것입니다. 이를 위해 비밀 API 키가 필요합니다. 이 가이드는 API 키를 생성하는 과정을 단계별로 안내합니다.

1단계: Anthropic API 콘솔로 이동하기

브라우저에서 https://console.anthropic.com/으로 이동하여 Anthropic 계정에 로그인합니다. 그러면 다음과 같은 페이지가 표시됩니다:

2단계: 'API 키 가져오기' 버튼 클릭하기

이 버튼은 메인 대시보드 페이지의 오른쪽 상단 근처에 있습니다.

3단계: '키 생성' 버튼 클릭하기

페이지 오른쪽 상단에서 '키 생성' 버튼을 찾아 클릭합니다.

4단계: 워크스페이스와 키 이름 입력하기

'기본값(Default)' 워크스페이스에 키를 생성하고, 키 이름을 입력합니다. 이 이름은 생성한 키를 식별하는 데 도움이 됩니다. 'Anthropic Course'라는 이름을 사용해 보겠습니다.

5단계: 키 복사하기

API 키가 팝업 창에 표시됩니다. 이 키를 복사하여 보관해 두세요 - 다음 영상에서 사용할 것입니다. 이 키는 한 번만 표시되므로 반드시 복사해 두세요!

실수로 창을 닫은 경우, 기존 키를 삭제하고 다시 생성하세요.
