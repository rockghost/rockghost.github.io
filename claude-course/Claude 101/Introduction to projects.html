프로젝트 소개

예상 소요 시간: 20분

학습 목표

이 레슨을 마치면 다음을 할 수 있습니다:

  • 프로젝트가 무엇인지, 언제 사용해야 하는지 설명하기
  • 이름, 설명, 공개 범위 설정으로 새 프로젝트 만들기
  • 프로젝트 지식 베이스에 문서 및 파일 추가하기
  • Claude의 동작을 안내하는 효과적인 프로젝트 지침 작성하기
  • 팀원과 프로젝트 공유하기 (Claude for Work 사용자)

동영상: Claude.ai에서 프로젝트 시작하기

핵심 요점

  • 프로젝트는 독립적인 작업 공간으로, 자체적인 메모리, 대화 기록, 지식 베이스, 맞춤형 지침을 갖추고 있습니다. 특정 업무 흐름을 위한 전용 환경으로 생각하세요.
  • 프로젝트 지식은 Claude의 이해를 향상시킵니다. 관련 문서를 업로드하면 Claude가 해당 프로젝트의 모든 대화에서 이를 참조합니다. 매번 같은 파일을 다시 업로드할 필요가 없습니다.
  • 프로젝트 지침은 Claude의 동작을 안내합니다. 어조, 전문성 수준, 응답 스타일 등을 지정할 수 있습니다. 이 지침은 프로젝트 내 모든 대화에 적용됩니다.
  • 프로젝트는 자동으로 확장됩니다. 지식 베이스가 컨텍스트 한도에 근접하면 Claude가 RAG(Retrieval Augmented Generation) 모드를 자동으로 활성화하여 응답 품질을 유지하면서 용량을 최대 10배까지 확장합니다.
  • Claude for Work 사용자의 경우 프로젝트로 협업이 가능합니다. 팀원과 프로젝트를 공유하여 모두가 동일한 컨텍스트, 지침, 축적된 지식을 활용할 수 있습니다.

프로젝트란 무엇인가요?

프로젝트는 Claude가 참조해야 할 지식을 저장하고, 특정 주제나 업무 영역을 중심으로 관련 대화를 구성하며, 동일한 공유 컨텍스트에 접근이 필요한 팀원들과 협업하는 데 이상적입니다.

프로젝트를 사용해야 할 때

프로젝트는 일회성 질문이 아닌 지속적인 작업을 할 때 특히 유용합니다. 다음과 같은 워크플로우가 있을 때 프로젝트 생성을 고려해 보세요:

  • 반복적으로 사용할 참조 자료 (회의록, 설문 결과, 보고서, 과거 데이터 등)
  • 일관된 요구사항 (항상 공식적인 언어 사용, 항상 출처 인용, 항상 우리 템플릿 따르기 등 Claude의 응답 방식에 대한 요구사항)
  • 팀 협업 필요성 — 여러 사람이 동일한 기반에서 작업해야 하는 경우

첫 번째 프로젝트 만들기

프로젝트를 설정하는 데는 몇 분밖에 걸리지 않습니다. 시작 방법은 다음과 같습니다:

1단계: 프로젝트 설정하기

  1. 왼쪽 사이드바에 마우스를 올리고 "프로젝트"를 클릭하거나, claude.ai/projects로 직접 이동하세요.
  2. 오른쪽 상단에서 "+ 새 프로젝트"를 클릭하세요.
  3. 프로젝트에 설명적인 이름을 지정하세요 (예: "Q4 마케팅 캠페인" 또는 "제품 문서화").
  4. 작업 중인 내용에 대한 간단한 설명을 추가하세요. Claude가 이 설명을 직접 보지는 않지만, 프로젝트의 목적을 이해하는 데 도움이 됩니다.
  5. 공개 범위 설정을 선택하세요: 비공개로 유지하거나 조직과 공유하세요 (Claude for Work 사용자).

2단계: 프로젝트 지침 추가하기

프로젝트 지침은 이 프로젝트의 모든 대화에서 Claude가 어떻게 동작할지를 알려줍니다. "지침"을 클릭하여 지침 패널을 여세요.

좋은 프로젝트 지침에는 일반적으로 다음이 포함됩니다:

  • 작업 중인 내용에 대한 맥락: "이 프로젝트는 우리 B2B 소프트웨어 제품의 마케팅 콘텐츠를 만들기 위한 것입니다."
  • 프로세스 지침: "먼저 이 독자층을 끌어들일 블로그 구조를 고려한 후, 초안을 작성하세요."
  • 어조 및 스타일 선호도: "전문적이지만 대화체 톤을 사용하세요. 가능하면 전문 용어를 피하세요."
  • 특정 요구사항: "마케팅 문구 끝에는 항상 행동 유도 문구(call-to-action)를 포함하세요."

지침 작성을 완료한 후 "지침 저장"을 클릭하세요. 이 지침은 이 프로젝트의 모든 대화에 적용되며, 설정한 사용자 기본 설정 및 스타일과 함께 작동합니다.

3단계: 지식 베이스 구축하기

프로젝트의 지식 베이스는 Claude가 참조해야 할 문서를 업로드하는 곳입니다. 프로젝트 메인 페이지 오른쪽에서 파일 메뉴를 찾을 수 있습니다.

"+" 버튼을 클릭하여 콘텐츠를 추가하세요. PDF, DOCX, CSV, TXT, HTML 등 다양한 파일 형식을 업로드할 수 있습니다. Google Drive에 연결하여 문서를 직접 연결할 수도 있습니다.

업로드할 내용:

  • 참조 문서 (브랜드 가이드라인, 스타일 가이드, 템플릿)
  • 배경 자료 (리서치 보고서, 회의록, 요구사항 문서)
  • Claude가 모방하길 원하는 작업 예시
  • 기술 문서 또는 사양서

유용한 팁: 파일 이름을 설명적으로 지정하세요. Claude는 파일 이름을 사용하여 올바른 정보를 이해하고 검색하므로, "document1.pdf"보다 "Q4-2024-Brand-Guidelines.pdf"가 더 유용합니다.

프로젝트가 대용량 지식 베이스를 처리하는 방법

많은 콘텐츠를 업로드하면 어떻게 되는지 궁금할 수 있습니다. 프로젝트는 RAG(Retrieval Augmented Generation)라는 기능을 통해 대용량을 자동으로 처리할 수 있도록 확장됩니다.

프로젝트 지식이 컨텍스트 창 한도에 근접하면 Claude가 RAG 모드를 자동으로 활성화합니다. 모든 프로젝트 콘텐츠를 한 번에 메모리에 로드하는 대신, Claude가 질문에 답하는 데 필요한 가장 관련성 높은 정보만 지능적으로 검색하고 가져옵니다. 이를 통해 응답 품질을 유지하면서 프로젝트 용량을 최대 10배까지 확장합니다.

프로젝트가 RAG 활성화 상태일 때 시각적 표시기가 나타나지만, 경험은 동일하게 느껴질 것입니다. 문서를 업로드하고, Claude와 대화하며, 컨텍스트 인식 응답을 받을 수 있습니다.

프로젝트 내에서 작업하기

프로젝트가 설정되면 Claude와 대화를 시작할 수 있습니다. 프로젝트 내의 각 대화는 자동으로 지식 베이스에 접근하고 프로젝트 지침을 따릅니다.

협업 기능

Claude for Work(Team 및 Enterprise) 플랜 사용자의 경우, 프로젝트는 협업 기능을 통해 더욱 강력해집니다.

권한 수준

프로젝트를 공유할 때 세 가지 권한 수준 중 하나를 선택할 수 있습니다:

  1. 보기 가능: 멤버는 프로젝트 콘텐츠를 보고, 지식에 접근하며, 대화할 수 있지만 변경은 할 수 없습니다. 토론 권한이 있는 읽기 전용 접근으로 생각하세요.
  2. 편집 가능: 멤버는 완전한 협업 권한을 갖습니다. 지침을 수정하고, 지식을 업데이트하며, 다른 멤버를 관리하고, 프로젝트에 적극적으로 기여할 수 있습니다.
  3. 소유자: 프로젝트 생성자는 누가 프로젝트를 볼 수 있는지 포함하여 모든 것을 제어합니다. 특정 사람과 공유하거나 프로젝트를 전체 조직에 공개할 수 있습니다.

프로젝트 공유하기

프로젝트를 공유하려면:

  • 공유하려는 프로젝트 열기
  • 프로젝트 이름 오른쪽의 "프로젝트 공유" 버튼 클릭
  • 이름 또는 이메일로 개별 멤버를 추가하거나, 이메일 주소 목록을 복사하여 붙여넣어 대량 공유 (이 경우 프로젝트가 상대방의 "나와 공유됨" 섹션에 표시됨)
  • 또는 "[조직 전체]와 공유"하여 팀 탭 내에서 프로젝트를 검색 가능하게 만들기

프로젝트를 공유하면 팀원들이 이메일 알림을 받으며, "나와 공유됨" 탭에서 공유된 프로젝트를 찾을 수 있습니다.

영감을 주는 프로젝트 예시

어디서 시작해야 할지 모르겠나요? 다양한 기능에 걸친 일반적인 프로젝트 유형은 다음과 같습니다:

  • Q4 제품 출시 : 제품 사양, 경쟁 분석, 메시지 브레인스토밍 메모를 업로드하세요. Claude가 모든 문의나 문서 초안 작성 시 이 맥락을 염두에 둘 것입니다.
  • 리서치 지원 : 경쟁 검토, 사용자 리서치 데이터, 고객 피드백을 한 곳에 집중시키세요. Claude가 출처를 종합하고, 보고서를 초안하며, 권고 사항 전반에 걸쳐 일관성을 유지하는 데 도움을 줄 수 있습니다.
  • 클라이언트 계정 허브 : 클라이언트의 브랜드 가이드라인, 과거 산출물, 커뮤니케이션 이력을 한 곳에 보관하세요. 제안서나 보고서 작성 시 Claude가 클라이언트의 톤을 맞추고 특정 맥락을 참조하도록 지침을 설정하세요.
  • 이벤트 기획 워크스페이스 : 행사장 계약서, 연사 약력, 참석자 데이터를 업로드하세요. Claude가 이벤트 테마와 일관성 있는 진행 순서 문서, 참석자 커뮤니케이션, 행사 후 보고서 생성을 도와줄 수 있습니다.
  • 채용 공고 생성기 : 과거 채용 공고, 팀 헌장, 내부 인원 요청 문서를 모으세요. Claude와 함께 팀의 실제 업무와 문화를 반영하는 채용 공고를 초안하세요.

프로젝트 모범 사례

프로젝트를 최대한 활용하려면:

  • 집중된 것부터 시작하고 점차 확장하세요. 모든 것을 위한 하나의 프로젝트를 만들려 하지 말고, 특정 사용 사례부터 시작하세요. 진행하면서 언제든지 콘텐츠를 추가할 수 있습니다.
  • 지식 베이스를 최신 상태로 유지하세요. 오래된 문서는 오래된 응답으로 이어질 수 있습니다. 프로젝트 지식을 주기적으로 검토하고 업데이트하세요.
  • 명확한 지침을 작성하세요. 원하는 것을 구체적으로 명시하세요. 모호한 지침은 일관성 없는 결과로 이어집니다.
  • 관련 문서를 그룹화하세요. 이렇게 하면 Claude가 다양한 출처 간의 연관성을 파악하고 더 포괄적인 응답을 제공하는 데 도움이 됩니다.
  • 문서를 이름으로 참조하세요. 질문할 때 특정 문서를 언급하여 Claude가 검색에 집중할 수 있도록 도와주세요: "Q3 보고서를 기반으로, 주요 고객 우려사항은 무엇이었나요?"

레슨 되돌아보기

계속 진행하기 전에 다음을 생각해 보세요:

  • 지속적인 컨텍스트를 가진 전용 프로젝트로 혜택을 받을 수 있는 진행 중인 작업은 무엇인가요?
  • 정기적으로 Claude에게 다시 업로드하거나 다시 설명해야 할 것으로 예상되는 문서는 무엇인가요?
  • 팀에 속해 있다면, 공유된 지식과 지침으로 혜택을 받을 수 있는 프로젝트가 있나요?
